# Завершение обычной игры — 2026-11-01, 03:09 MSK

## Подтверждённая причина

Это штатная остановка защитным watchdog, не падение игрового процесса.
Проверен текст существующей Konsole через read-only D-Bus
`org.kde.konsole.Session.getAllDisplayedText`; команды в терминал не отправлялись.

- Запуск `tools/run.sh`: **03:05:45.561**, GPU **53 °C**, процесс игры **145285**.
- Завершение: **03:09:38.115**, событие **`thermal_stop`**, GPU **70 °C**,
  установленный порог **70 °C**. Продолжительность **232.554 с**.
- Оболочка показывает код **86**, соответствующий `THERMAL_EXIT` в
  `tools/gpu_guard.py`.

Сырой относящийся к игре фрагмент сохранён в
`artifacts/crash-check-20261101/game-terminal.log`, структурированная сводка —
`artifacts/crash-check-20261101/summary.json`.

Отсечка проверена на настоящем пользовательском запуске. Устойчивую работу
ниже 70 °C оптимизации **пока не обеспечили**. Эти записи не отделяют мощность
самой игры от параллельных GPU-задач; полной температурной кривой этого запуска
нет. Новый тепловой прогон для диагностики не выполнялся.

## Что не относится к этому завершению

Единственный найденный после перезагрузки Redot core dump: PID **143036**,
SIGSEGV в **03:01:53**. Его command line содержит `--editor --import --quit`;
это отдельный импорт SPH GLSL, описанный в `2026-11-01-surface-water.md`, а не
пользовательский процесс 145285. Температуры этого импорта были 52–57 °C,
его guard завершился с `returncode=-11`, без `thermal_stop`.

В проверенном kernel-журнале после 02:45 новых NVRM/Xid/OOM не найдено.
При read-only проверке после остановки `nvidia-smi` отвечал: **45 °C, 21.49 Вт**.
Игра не перезапускалась, GPU/драйверные настройки не менялись.
