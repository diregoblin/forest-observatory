## Проверенная платформа и сборка

Сейчас проверены Linux x86_64, Redot 26.3 (`85e520394`), Forward+ / Vulkan и NVIDIA. Redot сообщает GDExtension API 4.5.2; нельзя выбирать bindings только по маркетинговому номеру версии. Бинарные расширения для Windows/macOS и других архитектур не подготовлены. Compatibility renderer и другие GPU не объявлены рабочими без отдельной проверки.

Нужны Git, CMake, C++17, Python 3 и отдельно установленный Redot. При необходимости укажи число задач через `HYDRO_BUILD_JOBS=4`. Команды выполняются в корне репозитория:

```bash
export REDOT_BIN=/absolute/path/to/redot.linuxbsd.editor.x86_64
./tools/build_hydro.sh
./tools/run.sh --headless --editor --import --quit
./tools/run.sh
```

Bindings автоматически получаются из `Redot-Engine/redot-cpp`, ветка `redot-26.3-stable`, закреплённый commit `ef6e110918198417521d87335a1bb9d883f5a5a4`. Скрипт проверяет существующий checkout и сохраняет локальные изменения. Библиотека устанавливается атомарным переименованием; работающий процесс продолжает использовать старую до перезапуска. Engine, службы и пользовательские сохранения сборка не меняет.

Лаунчер запускает Python-watchdog, который читает `nvidia-smi` и останавливает **свою** группу процессов при ≥75°C или потере телеметрии. Настройки драйвера, вентиляторов и соседние задачи остаются прежними. Python нужен для сборочных скриптов и watchdog. Для поддержки других видеокарт потребуется добавить и проверить чтение их телеметрии.

### Численные ядра без графики

Для моделей C++ не нужны GPU, Redot и bindings:

```bash
cmake -S native -B native/build-core -DFOREST_EXTENSION=OFF -DCMAKE_BUILD_TYPE=Release
cmake --build native/build-core --parallel 4
native/build-core/hydro_checks
native/build-core/fungi_checks
native/build-core/soil_checks
```

Здесь проверяются численные ядра. Сцены и интерфейс проверяются отдельно в Redot. [Алгоритмы и native-контракт](../native/README.md).

## Архитектура и точки входа

| Каталог / файл | Назначение |
|---|---|
| `data/forest.tres`, `scripts/settings.gd` | Сценарий, масштабы, разрешения, скорости |
| `data/plants`, `data/animals`, `data/fungi`, `data/soils` | Неизменяемые определения видов/материалов |
| `native/` | Float64-ядра воды, общей CNP-почвы, грибов и численные контроли |
| `scripts/trees.gd`, `animals.gd`, `habitat.gd`, `weather.gd` | Модели биологии/среды |
| `scripts/forest.gd` | Композиция, общий шаг, worker, транзакции сохранения |
| `scripts/*_view.gd`, `vegetation.gd`, `shaders/` | Отображение завершённых состояний моделей |
| `scripts/forest_hud.gd`, `soil_layers.gd`, `observation_panel.gd` | Интерфейс и read-only диагностика |
| `tools/` | Проверки, безопасный запуск, захват кадров |
| `verification/` | История конкретных опытов с датами/границами |
| `modules/fluid/` | Отдельное исследование SPH |

Прочитай [AGENTS.md](../AGENTS.md) перед изменением связей. Ключевые инварианты: один владелец почвенных C/N/P, конечные доноры, join перед доступом к worker-моделям, модельное время вместо frame-time, виды как ресурсы без `if species_id == ...`, одинаковая геометрия для изображения и picking. Визуальные изменения выполняются в представлении; запасы и расчётное дно принадлежат моделям.

При добавлении вида используй [каталог ресурсов](species.md), общие морфологические компоненты и [контракт движения](animal-motion.md). Новая модель обязана определить владельца запасов, SI-единицы, snapshot/restore, обмены и проверяемый нулевой случай.

## Проверки

```bash
./tools/check.sh
```

Полный путь собирает ядра/расширение, запускает численные проверки, импорт редактора и headless-интеграционные сценарии. Результаты — `artifacts/*.json` и логи; каталог игнорируется Git. Скрипт удаляет прежние выбранные отчёты перед запуском и требует `passed:true` в новых результатах. Прерванный прогон считается незавершённым.

Интерфейс и материалы проверяй в Forward+: открой сцену, осмотри изображение и проверь ввод. Например, [preview_grass_hud.gd](../tools/preview_grass_hud.gd) проверяет меню и карты через ввод, [check_pixel_style.gd](../tools/check_pixel_style.gd) — стили и неизменность моделей. Не запускай длительные GPU-прогоны без причины и не обходи температурный предел.

### Скриншоты

Кадры этой документации получены из текущей сцены Forward+ при 1440×900, seed 29017, пауза, без изменения пользовательского сохранения. Сезонный кадр снят в режиме просмотра на паузе. Карты показывают начальное состояние мира, до первого расчётного шага.

Воспроизведение на отдельном X11-дисплее без вмешательства в открытое окно:

```bash
# Xvfb должен уже существовать; скрипт ничего не устанавливает.
export XVFB_BIN=/absolute/path/to/Xvfb
./tools/preview_isolated.sh --script res://tools/capture_course_docs.gd
```

Если есть локальный `.preview-tools/usr/bin/Xvfb`, переменную можно не задавать. `preview_isolated.sh` поднимает собственный сервер, вызывает guarded launcher и убирает только свой сервер после завершения. Отчёт `artifacts/course-screenshots.json` фиксирует список кадров и сравнение byte-снимков моделей до/после. PNG сохраняются в `docs/images/`; `.gdignore` предотвращает их ненужный импорт в игровой проект. После захвата открой и осмотри картинки.

### Скрытые контрольные стили

Обычный запуск показывает только основной пиксельный вид. Для сравнений материалов:

```bash
./tools/run.sh -- --debug-render-modes
./tools/run.sh -- --baseline-style
./tools/run.sh -- --painterly-style
```

В этих запусках доступны кнопка вида и F8 для сравнения материалов. Диагностика воды и почвы находится в V, локальная карта грибного участка — в G.

## Если не запускается

| Симптом | Проверка |
|---|---|
| `Redot not found` | `REDOT_BIN` — абсолютный путь к исполняемому файлу редактора |
| `Native hydrology is not built` | Сначала `tools/build_hydro.sh`; смотри вывод CMake/компилятора |
| Неожиданная ревизия bindings | Скрипт намеренно не делает reset; проверь локальный checkout |
| Ошибка GPU telemetry / слишком высокая температура | Проверь `nvidia-smi`, дождись охлаждения; защиты не отключать |
| Меню работает, кадр сломан | Проверь Vulkan/Forward+, импорт, версию Redot и Terrain3D; сохрани лог |
| F9 отклоняет сохранение | Сравни версию поведения, геометрию и конфигурацию; не подменяй версии вручную |
| После изменения кода окно осталось прежним | Это старый процесс; новое расширение/сценарий применятся в новом запуске |
| Темп меньше выбранного | Сравни достигнутую скорость и длительность модельного шага |

При сообщении об ошибке приложи ревизию, ОС/GPU/версию Redot, шаги и небольшой лог. Не включай секреты и чужие пользовательские сохранения в публичный issue.
